PMP Exam Calculators

Three free calculators for the math on the PMP exam. Each one shows the formula, works a real example, and says where the formula comes from. No login.

Earned Value (EVM) Formulas and Calculator

CPI = EV / AC · SPI = EV / PV
CV = EV − AC · SV = EV − PV
EAC, ETC, VAC, TCPI

Enter PV, EV, AC and BAC to get all eight results, color-coded so you can see over or under budget and ahead or behind schedule.

PMBOK 8 prints every EVM formula in Table 5-1, including four ways to calculate EAC.

PERT Formula and Calculator

tE = (O + 4M + P) / 6
SD = (P − O) / 6

Enter optimistic, most likely and pessimistic estimates to get the expected duration, standard deviation, variance and confidence ranges.

PMBOK 8 prints only the triangular average (O + M + P) / 3. The weighted PERT version isn’t in the guide.

Free - No login

Communication Channels Formula and Calculator

n(n − 1) / 2

Enter the number of people, project manager included, and see the channel count plus what happens when people join or leave.

PMBOK 8 doesn’t print this formula. It lists the number of channels as an input to communication requirements analysis.

Free - No login

Which calculator does this question need?

  • The stem gives PV, EV, AC or BAC and asks about variance, a performance index, or a forecast: EVM.
  • The stem gives optimistic, most likely and pessimistic estimates: PERT. If it asks for a simple average of the three, that’s the triangular (O + M + P) / 3, not PERT.
  • The stem gives a team size, or people joining or leaving, and asks how many channels: communication channels. Count the project manager if the stem says “plus a project manager.”

What the 2026 exam says about formulas

PMI doesn’t publish a formula list, and the 2026 Exam Content Outline doesn’t name a single formula. The math sits inside tasks. In the Process domain (41 percent of the exam), Task 1 includes estimating work effort, Task 6 (Plan and manage finance) covers spend tracking and financial variations, and Task 8 (Plan and manage schedule) covers estimating tasks and analyzing schedule variation. In the People domain (33 percent), Task 8 is Plan and manage communication.

Frequently asked questions

Which PMP formulas do these calculators cover?

Earned value (CV, SV, CPI, SPI, EAC, ETC, VAC and TCPI), PERT three-point estimating (O + 4M + P) / 6 with standard deviation, and communication channels n(n − 1) / 2. Each calculator page explains its formula and works an example.

Does the PMBOK Guide 8th Edition print these formulas?

Only the earned value ones. PMBOK 8 prints the full EVM set in Table 5-1. For estimating it prints the triangular average (O + M + P) / 3, not the weighted PERT formula. It does not print n(n − 1) / 2; it lists the number of communication channels as an input to communication requirements analysis.

Does the 2026 PMP exam list which formulas it tests?

No. PMI doesn’t publish a formula list and the 2026 Exam Content Outline doesn’t name any formula. The math shows up inside tasks like Plan and manage finance, Plan and manage schedule, and Plan and manage communication.

Are the calculators free?

Yes. All three are free, need no login or signup, and work on desktop and mobile.
