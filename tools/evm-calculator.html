Earned Value Formulas Explained for the PMP Exam

Updated September 2026.

The three inputs, and BAC

Earned value management puts scope, schedule, and cost on one scale, money, so you can compare them. PMBOK 8 defines the three measurements it tracks for every work package (Section 5, Earned value analysis). Planned value (PV) is the budget assigned to the work that was scheduled to be done by now. Earned value (EV) is the budget assigned to the work that actually got done, and it can never exceed the PV budgeted for that work. Actual cost (AC) is what that work really cost, with no upper limit. Budget at completion (BAC) is the total planned value for the whole project, the cost baseline. Management reserve sits outside all of these.

Variances: are we over or under?

Cost variance (CV) = EV − AC The budget surplus or deficit for the work done so far. Positive is under planned cost, negative is over.

Schedule variance (SV) = EV − PV How far ahead of or behind the plan the completed work is, measured in money, not days. Positive is ahead of schedule, negative is behind.

Indexes: how efficient are we?

Cost performance index (CPI) = EV ÷ AC Cost efficiency. Exactly 1.0 means the work done so far cost exactly its budget. Above 1.0 is under planned cost, below 1.0 is over. A CPI of 0.80 means each dollar spent earned 80 cents of planned work.

Schedule performance index (SPI) = EV ÷ PV Schedule efficiency. Exactly 1.0 is on schedule, above is ahead, below is behind.

Forecasts: where does this end up?

Estimate at completion (EAC) is the expected total cost of the project, actual cost to date plus the estimate to complete. PMBOK 8 prints four versions in Table 5-1, and each comes with the condition that tells you when to use it. The exam tests the condition more than the arithmetic.

  • EAC = BAC ÷ CPI. When the CPI is expected to stay the same for the rest of the project. The default when a question gives no condition, and the one the calculator above uses.
  • EAC = AC + (BAC − EV). When the variance so far was a one-off and future work will run at the planned rate.
  • EAC = AC + (BAC − EV) ÷ (CPI × SPI). When both cost and schedule performance influence the remaining work.
  • EAC = AC + bottom-up ETC. When the original plan is no longer valid and the remaining work has to be re-estimated from scratch.

Estimate to complete (ETC) = EAC − AC What the rest of the work will cost. The guide also allows a bottom-up re-estimate in place of the formula.

Variance at completion (VAC) = BAC − EAC The projected surplus or overrun at the end. Positive is under planned cost, negative is over.

TCPI: the efficiency you'd need from here

TCPI = (BAC − EV) ÷ (BAC − AC)

The to-complete performance index is the cost efficiency the remaining work has to hit to finish on a target. Work remaining over funds remaining. Greater than 1.0 means the rest of the project has to run more efficiently than the plan, exactly 1.0 means the same, less than 1.0 means easier. PMBOK 8 gives two forms. The BAC form above targets the original budget. When the BAC is no longer viable and a new EAC has been approved, the EAC replaces it: TCPI = (BAC − EV) ÷ (EAC − AC). Whether a TCPI is achievable is a judgment call the guide ties to risk, time remaining, and technical performance, not to a fixed cutoff.

Worked example, PMP style

A project has a BAC of $450,000. At the status date, PV is $200,000, EV is $180,000, and AC is $225,000. Type those four numbers into the calculator above and you'll get every result below.

  • CV: 180,000 − 225,000 = −$45,000. Over planned cost.
  • SV: 180,000 − 200,000 = −$20,000. Behind schedule.
  • CPI: 180,000 ÷ 225,000 = 0.80. Each dollar spent earned 80 cents.
  • SPI: 180,000 ÷ 200,000 = 0.90. Work is coming in at 90 percent of the planned rate.
  • EAC (CPI continues): 450,000 ÷ 0.80 = $562,500.
  • EAC (one-off variance): 225,000 + (450,000 − 180,000) = $495,000.
  • EAC (cost and schedule): 225,000 + 270,000 ÷ (0.80 × 0.90) = 225,000 + 375,000 = $600,000.
  • ETC: 562,500 − 225,000 = $337,500 (using the first EAC).
  • VAC: 450,000 − 562,500 = −$112,500. Projected overrun.
  • TCPI (to the BAC): 270,000 ÷ 225,000 = 1.20. The rest of the work has to run 50 percent more efficiently than it has so far (CPI 0.80 to 1.20).
  • TCPI (to the EAC of $562,500): 270,000 ÷ 337,500 = 0.80. Same as the current CPI, which is exactly what BAC ÷ CPI assumes.

Read the shape of it: 40 percent of the value is earned, 50 percent of the budget is spent, and the three EAC versions land $105,000 apart from the same four inputs. That spread is why the exam asks which formula, not just what the number is.

The direction rule

  • Variances (CV, SV, VAC): positive is good, negative is bad, zero is on plan.
  • Indexes (CPI, SPI): above 1.0 is good, below 1.0 is bad, exactly 1.0 is on plan.
  • TCPI: the reverse. Above 1.0 means the remaining work is harder than planned, below 1.0 easier.
  • EAC vs BAC: EAC below BAC is under budget, above is over. VAC has the sign already.

Where it fits on the 2026 exam

PMI doesn't publish a formula list, so no one can promise you an EVM question or a count. What's documented: PMBOK 8 prints the formula set in Table 5-1 and lists earned value analysis as a tool of Monitor and Control Project Performance, Monitor and Control Schedule, and Monitor and Control Finances, which also outputs the cost forecast that carries the EAC. The 2026 Exam Content Outline puts the work in the Process domain, 41 percent of the exam: plan and manage finance includes monitoring financial variations, plan and manage schedule includes analyzing schedule variation, and evaluate project status includes measuring and updating project metrics. On agile projects the same math runs on story points per iteration, with PV and EV in points and AC from the team's hours, so don't assume EVM is predictive-only.

Common exam traps

  • Calculating when the question wants a decision. "CPI is 0.80 and SPI is 1.10, what should the project manager do?" is about reading the numbers (over budget, ahead of schedule) and picking the action, not about arithmetic.
  • The wrong EAC. Read the condition in the stem. "Expected to continue" is BAC ÷ CPI. "Won't happen again" is AC + (BAC − EV). All four results are usually in the answer choices.
  • SV in days. Schedule variance is in money. A question asking how many days behind is asking for something else.
  • TCPI read backwards. A TCPI of 1.20 is bad news for the remaining work, not good.
  • The EV chart. Graphic-based questions can show the three curves. PV is the plan line, AC and EV are the actuals; EV below PV is behind schedule, AC above EV is over budget.

Common Questions

What are the earned value management (EVM) formulas for the PMP exam?

The core set is cost variance CV = EV - AC, schedule variance SV = EV - PV, cost performance index CPI = EV / AC, and schedule performance index SPI = EV / PV. The forecasting set is estimate at completion (EAC, four versions), estimate to complete ETC = EAC - AC, variance at completion VAC = BAC - EAC, and to-complete performance index TCPI = (BAC - EV) / (BAC - AC). PMBOK 8 prints all of them in Table 5-1.

What is the CPI formula and what does it mean?

CPI = EV / AC, earned value divided by actual cost. It measures cost efficiency: a CPI of 1.0 means the work done so far cost exactly what was budgeted, above 1.0 means under planned cost, below 1.0 means over planned cost. A CPI of 0.80 means every dollar spent has earned 80 cents of budgeted work. SPI = EV / PV is the schedule twin and reads the same way.

Which EAC formula should I use on the PMP exam?

Match the formula to the condition the question states. If current cost performance is expected to continue, EAC = BAC / CPI. If the variance was a one-off and future work will run at the planned rate, EAC = AC + (BAC - EV). If both cost and schedule performance affect the remaining work, EAC = AC + (BAC - EV) / (CPI x SPI). If the original plan is no longer valid, EAC = AC + a bottom-up ETC. When the question gives no condition, BAC / CPI is the default.

Is earned value on the 2026 PMP exam?

PMI does not publish a formula list, so nobody can promise a count. What's documented: PMBOK 8 prints the full EVM formula set in Table 5-1 and lists earned value analysis as a tool in three monitoring processes, and the 2026 Exam Content Outline's Process domain, 41 percent of the exam, includes monitoring financial variations, analyzing schedule variation, and measuring project metrics. Expect EVM inside a scenario, usually as an interpretation question, sometimes as a chart.
